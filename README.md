# 🎬 StreamFlix – Subscription Growth Analysis

## 📌 Project Overview

**StreamFlix Subscription Growth Analysis** is a data analytics project developed using Microsoft Power BI to analyse subscription performance for a fictional OTT platform, StreamFlix Media Pvt. Ltd.

The project uses a simulated dataset covering **January 2024 to September 2026** to explore subscriber growth, revenue performance, customer churn, retention, regional trends, and content engagement.

The main objective is to transform subscription data into meaningful business insights through interactive dashboards and visual analytics.

## 🎯 Project Objectives

- Analyse subscriber growth and lifecycle stages.
- Evaluate revenue contribution across subscription plans.
- Monitor customer churn and retention.
- Track monthly revenue and active subscribers.
- Compare new and ended subscriptions.
- Analyse subscription performance across regions.
- Understand content engagement by genre and title.
- Develop an interactive dashboard to support business decision-making.

## 📊 Dashboard Overview

The project consists of two interactive dashboard pages.

### 1. Overview Dashboard

Provides a consolidated view of subscription performance through:

- Subscriber Lifecycle Funnel
- Revenue Share by Subscription Plan
- Churn Rate by Plan
- Usage Hours by Genre
- Retention Rate by Plan and Segment
- Top 10 Content by Usage Hours

**Key Performance Indicators:**
- Total Subscribers
- Active Subscribers
- Total Revenue
- Churn Rate
- Retention Rate
- Month-on-Month (MoM) Performance

### 2. Monthly Analysis Dashboard

Focuses on subscription performance and trends over time:

- Monthly Revenue Trend
- Active Subscribers by Month
- New vs. Ended Subscriptions
- Monthly Retention and Churn Trend
- Regional Subscription Volume and Growth

### Interactive Features

- Dynamic slicers and filters
- Interactive charts and visuals
- Navigation between dashboard pages
- KPI cards with MoM indicators
- Conditional formatting

## 🔍 Methodology

The project followed a structured data analytics workflow:

1. **Collect:** Prepared simulated subscription-related datasets.
2. **Understand:** Reviewed data structure, attributes, and business requirements.
3. **Clean:** Inspected and transformed data using Power Query.
4. **Model:** Organised subscription data with supporting dimension tables and a Calendar table.
5. **Analyse:** Developed DAX measures for KPIs and monthly comparisons.
6. **Visualise:** Designed interactive dashboards in Power BI.
